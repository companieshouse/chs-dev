# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those
roles to the actual label strings used in this repo's issue tracker.

| Upstream label    | Our tracker label | Meaning                           |
| ----------------- | ----------------- | --------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer evaluates the issue    |
| `needs-info`      | `needs-info`      | Waiting on reporter for more info |
| `ready-for-agent` | `ready-for-agent` | Specified; ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires a human to implement     |
| `wontfix`         | `wontfix`         | Will not be actioned              |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the
corresponding label string from this table.

Edit the "Label in our tracker" column to match whatever vocabulary you actually
use.
